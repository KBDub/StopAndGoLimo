service-thin-rect-card — horizontal variant
Current state: Vertical only. Full-width (width: 100%), stacks as a column list. No horizontal prop exists.

Can we do it? Yes, cleanly. The card's structure (icon + label in a flex row) is already horizontal internally — the only thing "vertical" about it is its full-width block behavior. A :horizontal boolean prop would add a second CSS block:

.sg-svc-rect.is-horizontal {
    width: auto;
    padding: 0.625rem 1rem;
    font-size: 0.875rem;
    border-bottom: 3px solid transparent;
    box-shadow: none;
}
.sg-svc-rect.is-horizontal:hover {
    background: var(--navy);
    box-shadow: none;
    border-bottom-color: var(--champagne);
}

Wrap a row of them in a flex gap-1 bg-navy bar and they become a sticky page-index anchor strip — exactly what a gallery section header needs. This is the right pattern.
